# 中区・南区 求人手帳

広島市中区・南区の求人だけを毎朝まとめて見るための、個人用のPWAです。

- `scripts/fetch.py`：GitHub Actionsで毎朝1回、ハローワークインターネットサービスの検索結果の一覧ページを読み、`data/jobs.json` を更新します。ページ間は3秒以上あけ、詳細ページや連絡先は取得しません。
- `index.html`：`data/jobs.json` を読み込んで表示します。「気になる」「応募した」などの状態は、各端末のブラウザにだけ保存されます。

求人情報はハローワークインターネットサービスに公開されている内容です。応募の前に、必ずハローワークで最新の求人票を確認してください。
